Monitoring system 
==================

You can use ezServerMonitor (ezSM) instead of the RRD method described below.
Download it from https://www.ezservermonitor.com/.

   cd /var/www/html
   git clone https://github.com/shevabam/ezservermonitor-web.git
   mv ezservermonitor-web esm
   cd esm/conf/
   
   Edit esm.config.json and follow the configuration documentation:
   https://www.ezservermonitor.com/esm-web/documentation
   Edit html/buttons.html in your deployed dashboard and change:
   
   <a class="button link" href="sysinfo.php">&nbsp;System Info&nbsp;</a>
   to:
   <a class="button link" target="_blank" rel="noopener" href="esm/">&nbsp;System Info&nbsp;</a>
   
   or you can add to sysinfo.php below line <?php include_once 'buttons.html'; ?>  following html code:
   
   <div>
   <a class="button link" target="_blank" rel="noopener" href="esm/">&nbsp;eZ Server Monitor&nbsp;</a>
   </div>

You can put in esm.config.json monitor services like HBMonitor, HBlink like:
 
    "services": {
        "show_port": false,
        "list": [
            {
                "name": "Web Server",
                "host": "localhost",
                "port": 80,
                "protocol": "tcp"
            },
            {
                "name": "HBMonitor",
                "host": "localhost",
                "port": 9000,
                "protocol": "tcp"
            },
            {
                "name": "HBLink",
                "host": "localhost",
                "port": 4321,
                "protocol": "tcp"
            }

Alternative SYSInfo based on rrdtools and scripts
====================================================
Below is a description of how to monitor the system using rrdtools and scripts :

Install package:

   sudo apt-get install rrdtool -y
   
Change scripts to execute:

  chmod +x /opt/HBMonv2/sysinfo/cpu.sh
  chmod +x /opt/HBMonv2/sysinfo/graph.sh
  chmod +x /opt/HBMonv2/sysinfo/rrd-db.sh
  
Run script  create database

   cd /opt/HBMonv2/sysinfo
   ./rrd-db.sh 


Edit file
    
  /opt/HBMonv2/sysinfo/cpu.sh

Set WEB_PATH to the web directory containing HBMonv2,
for example /var/www/html or /var/www/html/hbmon.

Edit file
    
  /opt/HBMonv2/sysinfo/graph.sh

Set WEB_PATH to the web directory containing HBMonv2,
for example /var/www/html or /var/www/html/hbmon.


Configure temperature collection for your hardware.
On Raspberry Pi or PC, you can use the sensors package to read CPU temperature.

If you do not want to show temperature, comment out the collection line.

Copy file sysinfo-cron to /etc/cron.d/ and restart cron:
   systemctl restart cron
   

Optional display network traffic
===============================

Install MRTG and SNMP:

  sudo apt-get install mrtg snmp snmpd -y

Edit file

  /etc/snmp/snmpd.conf

and set as below


   rocommunity public  localhost 
   #rocommunity public  default    -V systemonly               
   #rocommunity6 public  default   -V systemonly


Restart snmpd

  systemctl restart snmpd


Create config for mrtg:

  cfgmaker -zero-speed=10000  public@localhost > /etc/mrtg.cfg

Edit /etc/mrtg.cfg and set WorkDir to the directory that stores images:
path to your webserver html directory where is html files for HBMon:

   WorkDir:/var/www/html/hbmon/img/mrtg
   
   or 
   
   WorkDir:/var/www/html/img/mrtg

Put below lines in section your network card 
Replace localhost_2 with the interface name generated by cfgmaker in mrtg.cfg.

 XSize[localhost_2]: 600 
 Options[localhost_2]: growright, bits
 Unscaled[localhost_2]: d

Tune MaxBytes, for example to 50000, to set the graph's vertical scale.

Edit the deployed sysinfo.php page to select the graph you want to display,
and verify the MRTG image name, for example:
<img alt="Daily network traffic" src="img/mrtg/localhost_2-day.png" />
